# Supplementary materials

**Constraint-guided construction of power-system operating conditions from natural-language requirements**

[Supplementary information](supplement.pdf) provides the experimental settings, evaluation criteria, additional comparisons, and computational costs cited in the paper (Sections S1–S8).

| Material | Contents |
|---|---|
| [Results](results/README.md) | Case-level outcomes, load and voltage changes, line loading, paired token counts, and power-flow settings |
| [Operating requirements](requirements/) | Recorded requirements for the twelve main cases and six additional cases |
| [Case examples](examples/README.md) | Generated specifications illustrating fixed-load treatment and requirement interpretation |

The materials support the results reported in the paper. The original PowerFactory network projects and a complete executable implementation are not included.
