# Constraint-guided construction of operating points for power-system simulation

Supplementary materials for the accompanying paper.

| Material | Contents |
|---|---|
| [Current experimental setup](experimental_setup.md) | Simulation environment, model settings, evaluation procedure, and equipment labels |
| [Results](results/README.md) | Case-level outcomes, load and voltage changes, line loading, token counts, and recorded power-flow settings |
| [Operating requirements](requirements/) | Requirements for the twelve main cases and six paired cases, identified by the case numbers used in the paper |

Device names in the reported requirements and result tables follow the paper. Original model responses and request excerpts retain their recorded labels; the [equipment table](experimental_setup.md#equipment-labels) gives the correspondence.

The current software environment and generation settings are given in [Experimental setup](experimental_setup.md). The retained `supplement.pdf` is an earlier supplementary note.

The original PowerFactory network projects and a complete executable implementation are not included.
