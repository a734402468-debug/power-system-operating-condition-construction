# Constraint-guided construction of operating points for power-system simulation

Supplementary materials for the accompanying paper.

[Supplementary information](supplement.pdf) reports the experimental settings, evaluation criteria, additional comparisons, and computational costs. The files below provide the operating requirements and numerical records used in the analysis.

| Material | Contents |
|---|---|
| [Results](results/README.md) | Case-level outcomes, load and voltage changes, line loading, paired token counts, and power-flow settings |
| [Operating requirements](requirements/) | Original Chinese requirements for the twelve main cases and six paired cases, identified by the case numbers used in the paper |
| [Case examples](examples/README.md) | Selected model responses illustrating fixed-load treatment and requirement interpretation |

The original PowerFactory network projects and a complete executable implementation are not included.
